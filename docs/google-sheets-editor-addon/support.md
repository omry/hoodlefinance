## Report An Issue

GitHub issues:

https://github.com/omry/hoodlefinance/issues

When reporting a problem, include:

- the exact formula you used
- the exact result or error message
- the ticker, ISIN, or currency pair involved
- whether the issue happened in the manual script install or the add-on

## Known Limits

HoodleFinance has important limits, including:

- some lookups depend on unofficial APIs or public website behavior
- upstream source changes may break lookups without warning
- not all `GOOGLEFINANCE` attributes are supported
- support varies by market, exchange, identifier form, and upstream source

For broader project limitations, see the main README and API documentation.
