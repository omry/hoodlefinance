# Installation

Install HoodleFinance as a Google Sheets™ add-on from the Google Workspace Marketplace™.

## Install From The Marketplace

1. Open the [HoodleFinance listing in Google Workspace Marketplace™](https://workspace.google.com/marketplace/app/hoodlefinance/826310867331)
2. Click **Install**.
3. Choose the Google account and spreadsheet you want to use.
4. Review the permissions prompt and approve it.
5. The add-on is now installed for your account. Enable it in each spreadsheet you want to use.

## Activate In A Spreadsheet

Enable HoodleFinance in each spreadsheet you want to use:

1. Open or reload the spreadsheet.
2. Open **Extensions -> Hoodlefinance -> Enable**.
3. Confirm the toast says the add-on was enabled for that spreadsheet.

If you want to use HoodleFinance in another spreadsheet, repeat the activation step there.

## Troubleshooting

If HoodleFinance is installed but not available in a spreadsheet:

1. Open **Extensions -> Add-ons -> Manage add-ons** and confirm that HoodleFinance is installed for your account.
2. Reload the spreadsheet tab.
3. Open **Extensions -> Hoodlefinance -> Enable**.
4. If the issue continues, remove and reinstall the add-on.
